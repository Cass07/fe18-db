## 만자천홍 Database
- 데이터마이닝이 불가능해서 나의 플레이와 다른 파붕이들의 제보를 모아서 정리합니다

### 업데이트 예정 데이터
- 캐릭터 기본 성장률, 개인 패시브
  - 20레벨 되면 개인 스킬 (따로 장착해야함) 따는거같은데 그것도 최대한 모아서 정리해봄
- 클래스 성장률, 보정스탯, 요구조건, 클래스 스킬, 마스터 스킬
- 1부 루트별 외전이랑 등장날짜
<br>
- 캐릭터 성장률 + 클래스 성장률 계산기 만들거임
- 영입 캐릭터 레벨 스케일링 규칙 정리하면 예측성장계산기도 만들수도있고 아닐수도있음
